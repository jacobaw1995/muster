DESKTOP ADAPTATION
Home/Map becomes a two-pane layout: a persistent left rail (search, filters, scrollable event list, ~420px) beside a large map that fills the remaining viewport. The bottom nav becomes a slim top bar with the same four destinations plus the wordmark. Event detail and Create open as a right-side panel over the map (not a modal) so the map stays visible while browsing. Impact and Itinerary keep their mobile structure but center in a max-width 720px column.
PWA NOTES
Full-bleed frame with no browser chrome, safe-area padding already built into the status bar and nav. Bottom nav sits above the home-indicator inset. Dark theme matches a manifest theme-color of #0e0f0c so the OS status bar blends in on install.
TRY IT
Tap a pin or card to open Event Detail. RSVP, then check the Itinerary tab. Toggle LIVE / LOADING / NO EVENTS above the map. Flip Impact between YOU and OPERATOR STANDARD. Tap the sun/moon in the status bar for light mode.
